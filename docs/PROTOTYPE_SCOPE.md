# Prototype 1 scope

## In scope
- two-organisation Fabric development network
- dataset registry record
- synthetic CID/hash
- consent state
- research access request
- approve/reject/revoke
- event emission
- state/history queries

## Explicitly out of scope
- actual MRI bytes
- real IPFS integration
- PHI
- authentication hardening
- DICOM ingestion
- FHIR
- federated search
- AI
- production deployment

This isolation is intentional: it proves the blockchain role first.
